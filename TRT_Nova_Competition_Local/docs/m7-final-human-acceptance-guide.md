# NOVA 人工体验清单

更新：2026-09-08。你只需像真实用户一样操作，代码、数据库、接口、云候选测试由技术侧负责。这里不再夹带安装命令、旧阶段报告和测试日志。

**用途分开：** 会议演示只走[讲解指南](../../../../../交付报告/2026-09-08_会议材料/讲解与演示指南.md)中的主线；最终体验用本清单。当前状态与证据看[先看这里](./先看这里.md)。

## 开始前

技术侧把同一个本地项目、后端和数据库准备到可操作状态。未加载就先排障，不用你重建库或跑脚本。只使用测试植株、无隐私图片和文档；重要数据不参与删除测试。总计预留 30–45 分钟，实际模型等待另算。

每项记录“通过 / 问题 / 未执行”，问题只需附步骤、输入和截图。没有亲自试过不能默认打勾。本地开发身份不能证明两个真实微信账号隔离。

## 1. 导航、资料与知识库

- [ ] 四个 Tab 分别第一次和第二次打开，比较反馈和等待；来回切换不空白、不卡死、不重复跳转。
- [ ] 修改测试昵称和头像，返回后再打开，图片、头像框和字段对齐正常。
- [ ] 知识库可返回，搜索后能阅读来源；上滑不会把内容截到状态栏或胶囊下。
- [ ] 关于页返回“我的”不触发无意义震动；在开发工具中无法感知实体震动的项留给手机。

## 2. 无植宠与附件草稿

- [ ] 没有植宠时也能聊天、选图片和支持的文档。选中后出现在输入框，尚未发送。
- [ ] 取消文件选择不清空已有文字或草稿；原生选择器返回后草稿可用。
- [ ] 补充文字后点箭头，只发送一次。离开页面回来，已发送文件和回复还在。
- [ ] 文件不支持、损坏、超过限制或网络失败时有清楚提示，不能假装分析成功。

没有空花园账号时，技术侧准备隔离测试环境；不要为了这一步删除你的全部植株。原生手机拍照和系统选择器另在云端手机阶段验。

## 3. 建档与多植株范围

- [ ] 新建“验收月季”和另一盆测试植株，手动录入和拍照辅助入口都可使用。
- [ ] 未知品种也能建档。修改名称、封面、位置，重开后保留。
- [ ] 切换植株时，档案、任务、日记和会话范围随之变化，不串到另一盆。
- [ ] 当前选中第二盆时发月季图片只问介绍，不应给第二盆凭空绑定诊断或任务。

## 4. 连续会话与自动摘要

- [ ] 不开启跨会话记忆，先说“以后叫我 dola 吧”，立即问“你怎么称呼我？”“刚才聊了什么？”，同会话应接得上。
- [ ] 给同一植株新建第二个会话，再切回第一个，原对话仍在。
- [ ] 开启一次自动摘要，再说明测试称呼和一个养护偏好。稍后查看摘要，未必每句话都新增内容，但不得在失败时谎称已更新。
- [ ] 新建会话问称呼，应使用有效摘要；进入编辑，整段改为“你希望我称呼你为豆包，喜欢简短回答”，保存、重进，再在新会话验证。
- [ ] 关闭摘要后，新会话不再使用它；清除后新会话不恢复旧称呼。原会话仍可引用它自己的原话，这不算清除失败。
- [ ] 在两个页面/会话引发摘要版本变化时，冲突应保留编辑草稿，不静默覆盖。复杂并发的代码验证由技术侧做。

长对话、原文分页、来源删除、跨账号、并发和摘要故障已由技术测试覆盖；你可按真实使用继续长聊，评价是否连贯，不需要手工凑测试轮数。保存全部原文不保证模型逐字复述全部内容。

## 5. 图片、文档与输入框

- [ ] 发月季图并补“这是什么，只介绍，不安排任务”。有分析和可见迹象边界，没有擅自出任务。
- [ ] 文档准备一句独有事实，例如“测试月季位于东窗”；发送后追问该事实，不应串用此前图片描述。
- [ ] 选择功能后继续输入自己的文字，没有自动塞进提示词、额外叉号或第二处重复功能标签。
- [ ] 在功能右侧连续输入 `123456111111`，字符顺序和光标不乱跳；连续退格只删除相邻内容。
- [ ] 把光标放到功能紧挨着的右侧，一次 Backspace 删除整枚功能，保留其他文字；Enter 换行，箭头发送。

9 月 8 日光标修复已有用户“没问题了”反馈；本清单保留它作为后续回归项，不代表这一项仍未修复。

## 6. 消息重写与撤回

- [ ] 阅读时无常驻低频操作栏。长按本人文字/图文消息，可复制或重新编辑。
- [ ] 编辑后原文字和保存过的附件回到输入框；发送建立新分支，原会话保留。
- [ ] 新分支继续追问，不能把被替换的后半段当作新对话事实。
- [ ] 撤回最新完整轮次后，不再出现在当前有效上下文；界面没有承诺撤回很早的任意轮次。
- [ ] 助手消息没有操作菜单是当前未实现项，不作为已完成能力演示。

## 7. 任务、日历与完成记录

- [ ] 说“不要给我创建任务”时没有任务候选。普通养护建议不能变成任务。
- [ ] 明确要求一个当日观察任务，先取消，日历无新增；再申请并确认一次，只出现一条正确归属的任务。
- [ ] 在预览或表单改日期、内容、重复方式，首页、植株详情和周/月日历一致。
- [ ] 延期、编辑、完成和删除测试任务都可用。周期任务完成后生成下一次，不连续补发历史任务。
- [ ] 连续记录和徽章与实际有计划的养护日一致，无任务日不误断。
- [ ] 当前站内提醒可用，小程序关闭后的微信订阅消息尚不属于已完成能力。

## 8. 日记、天气与失败状态

- [ ] 写无图、带一图、带三图的测试日记，重开后内容和顺序不变；可编辑和删除。
- [ ] 任务完成形成养护事件，自己写的图文日记是另一种记录，不混淆。
- [ ] 手动选择城市，显示天气来源和时间；定位拒绝时仍能手动选择。
- [ ] 断网或模型不可用时有明确失败提示，天气最多展示带时间的真实旧缓存，不编实时数字。
- [ ] 网络恢复后再操作可用，重试不重复创建任务；基础建档、任务和日记不以 AI 成功为前提。

## 9. 隔离、归档与清理

- [ ] 清图片缓存后，服务器已保存的封面、对话附件和日记仍能重新显示。
- [ ] 归档一盆测试植株，按产品入口查看时保留历史；永久删除另一盆测试植株前有影响范围提示。
- [ ] 确认永久删除后，该盆记录不再用于对话；其他植株的数据保留。
- [ ] 退出再登录后不混用上一个用户的画面、缓存或未完成请求。

跨账号底层测试由技术侧负责。本地固定开发身份下反复换微信登录，不能当作真实账号隔离通过。真实两个账号的验收留到云端。

## 云端与手机：现在不用你测候选代码

当前云候选由技术侧本机验证，尚未部署，你现在没有可用的云端体验码要验。

以后获准部署、技术侧验证通过并提供实际可用体验码后，再由你：

1. 关闭电脑本地后端，手机使用独立网络扫码，从真实微信登录开始。
2. 按上方主线完成建档、真实拍照/相册/文档、拒绝权限后恢复、确认任务、日记与重开。
3. 杀掉小程序后重进，检查原件、会话和摘要。
4. 与另一位真实体验成员分别登录，不能互相看到私有植株、任务、文件或记忆。
5. 记录手机型号、微信版本，分开看冷启动与再次进入速度、系统键盘和真实震动。

没有这些证据不能把本地通过升级成云端/手机通过。技术侧另验真实 SSM/COS 权限、数据库 TLS、网络、迁移与备份，不转交给你跑命令。
