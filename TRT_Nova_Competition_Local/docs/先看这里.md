## 当前能完成什么

| 需求 | 本地版对应能力 |
|---|---|
| 一盆植物的持续养护 | 建档与封面、今日任务、周/月日历、打卡、图文成长时间轴 |
| 能自然交流、接着聊 | NOVA 普通对话、完整会话与有效分支、长对话摘要和原话检索 |
| 跨会话记忆可用且可控 | 用户一次开启，AI 增量整理；整段编辑、关闭、遗忘 |
| 图片和文档不再一次性 | 先进入草稿，可补文字；发送后持久化，切页/重开恢复 |
| 操作不挤占阅读空间 | 本人消息长按复制、重新编辑、最新完整轮次撤回；编辑生成新分支 |
| 工具不能擅自办事 | 明确意图生成任务候选，用户确认后由业务 API 校验保存 |
| 有知识和环境依据 | 17 种植物、10 篇已批准临时 MVP 文章；真实天气与确定性节气 |

内联功能在原生 editor 的文字流中；Enter 换行、箭头发送。9 月 8 日光标跳到开头的问题，修复后已得到用户“没问题了”的反馈。早期系统键盘自动化失败仍保留，不再把它写成当前用户尚未验收。

会话原话保存到用户删除，不再沿用“20 轮/30 天自动清理”。每轮模型输入仍有长度限制，保存不等于逐字记住。自动摘要默认关闭，开启后才跨会话整理。清摘要不等于删除原会话。

当前 Agent 是内部 PlantPetRuntime，借鉴 PI 分工，没有安装官方 PI 作为生产运行时。图文仍有专用链；规则保留参数、归属和任务权限约束，旧链回退仍可能误拒。没有多 Agent、知识图谱、后台自治或硬件自主控制。
