# Phase 3 按稳定会话抽样并以能力完整性决定接管

M7 Phase 3 不按旧意图正则决定问题是否值得回答，也不一次切换全部流量，而是按当前鉴权账号与会话的 HMAC 指纹稳定抽样。新 `PlantPetRuntime` 只在本轮不依赖尚未迁移的任务、记忆、附件、当前植宠状态、高风险或安全能力，且模型结果通过工具、来源、隐私和内容完整性检查时接管回复；否则由 legacy 链路保存并返回，正式任务仍只能生成等待用户确认的候选。

## Consequences

- 同一账号的同一会话不会因 Query 文本变化在灰度组和对照组之间随机跳动。
- provider 超时、空回复、非法工具参数、当前植宠私有状态读取和来源缺失都自动回落 legacy，不把半成品展示给用户。
- 灰度开关默认关闭；启用时从小比例开始，并保留单一环境变量回滚。
- Phase 3 不新增记忆工具、业务写工具、设备工具、数据库表、部署单元或后台 Agent。
