# 团队试测说明

更新：2026-09-10。当前作为团队试测版本收集问题，不是正式发布或全部验收完成。

## 使用哪个版本

- Git 分支：competition-local-cloud。
- 本轮手机试测使用 TRT_Nova_Competition_Cloud 生成的客户端，不是本地演示版或旧 LastScf 目录。
- 向维护者领取最新的“登录资料修复”预览码；旧预览码不包含本次修复。测试账号需具备当前小程序的测试权限，不能通过更换目录或关闭域名校验绕过。
- Git 只提供源码、依赖锁和模板，不携带真实凭据、本机配置、node_modules、生成客户端或验收记录。需要自行生成客户端的开发成员，按[根目录 README](../README.md)配置；不要直接上传带占位地址的源码根目录。

## 本次登录修复

原“使用微信头像昵称”按钮会用旧接口返回值覆盖整个资料表单。本次改为微信原生头像选择，按钮明确显示“选择微信头像”；昵称仍通过昵称输入框选择或输入。

换头像只改头像，换昵称只改昵称；取消选择不清空，保存期间不接受迟到的头像回调。“清空重填”仍保留为明确的重置操作。登录页视觉样式暂未重做，后续按[HTML 原型确认流程](./ui-taste-and-prototype-workflow.md)迭代。

## 建议试测顺序

1. **登录资料**：先选头像并填写昵称，再点“选择微信头像”后取消，确认两项未回退。只换头像，确认昵称不变；保存后重新打开，确认资料仍在。首次登录与已有资料都要覆盖。
2. **植物档案**：新建一株明确标记为测试用的植物，修改昵称和位置，确认首页与详情一致。
3. **养护助手**：分别测试文字、非隐私植物图片和小型测试文档。检查发送、取消选择、返回后草稿、来源引用及长回答滚动。
4. **任务与日记**：产生任务候选后分别确认和取消；日历中完成任务；新增和编辑带图片的日记，重新打开核对。
5. **知识与返回路径**：查看文章和植物图鉴，尝试有结果与无结果的搜索；检查四个 Tab 与返回按钮。
6. **不同用户**：由至少两名真实微信用户分别建测试记录，检查各自列表、图片和会话是否只属于自己。更完整的跨账号接口负例由开发侧配合验证。

测试只用非隐私样本，不上传真实证件、密码、工作密文或他人的聊天记录。清理时仅删除自己明确建立的测试记录。

- 本轮产品自动测试 513 项、云适配测试 41 项、登录与身份定向检查 15 项通过。它们是自动测试证据，不替代手机操作。
- 修复客户端在开发工具中完成真实微信登录、已存资料读取和表单保留逻辑复验，云端资料未被回归操作改写。开发工具中的头像成功/取消回调检查不是手机原生选择器验收，需按上面的第 1 项实测。
