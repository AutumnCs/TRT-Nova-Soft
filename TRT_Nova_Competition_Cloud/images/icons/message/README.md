# 消息操作图标来源

本目录的 `copy.svg`、`pencil.svg` 与 `undo-2.svg` 来自
[Lucide](https://github.com/lucide-icons/lucide) 官方图标库，提取日期为 2026-08-31。

- 上游路径：`icons/copy.svg`、`icons/pencil.svg`、`icons/undo-2.svg`
- 上游提交：本轮调研时的 `main`
- 许可证：Lucide ISC License；其中由 Feather 派生的图标按上游 LICENSE 中列出的 MIT 条款使用

图标未以文字、emoji、CSS 图形或手绘 SVG 替代；业务代码只负责尺寸、透明度和点击状态。

2026-09-07 增加功能标签的 `plug.svg`，来自同一上游 `icons/plug.svg`（main）；仅将 `currentColor` 固定为产品蓝色以支持小程序 image。许可沿用上述 Lucide/Feather 条款。
