# 植宠产品语境

本表统一植宠项目中的产品语言，避免把交互内容、长期关系信息和真实业务状态混成同一类数据。

## 角色与对象

**NOVA**：
面向用户的植物养护伙伴，围绕植宠、养护和连续关系提供对话与受控建议。
_Avoid_: 通用聊天机器人、数据库代理

**植宠**：
归属于某位用户的一盆真实植物在产品中的持续数字对象，包含其档案、养护历史和关联设备。
_Avoid_: 植物条目、聊天角色

**当前植宠**：
用户在当前会话中明确选中的植宠；未选中时，NOVA 不得自行指定一盆植宠作为操作对象。
_Avoid_: 默认植物、最近植物

## 信息与连续性

**会话**：
用户与 NOVA 的一条可独立继续、编辑或分支的交互序列。
_Avoid_: 长期记忆、聊天缓存

**有效会话分支**：
由消息快照和会话事件共同投影出的当前可见历史；被撤回的轮次和被重新编辑替代的旧分支不再进入后续模型上下文。
_Avoid_: 删除全部历史、把所有历史分支同时喂给模型

**Agent 状态**：
一轮运行期间的消息、工具轨迹、候选结果和中止状态；请求结束后不得被当作长期真相保存。
_Avoid_: 用户记忆、业务事实

**长期记忆**：
用户允许跨会话使用、可查看和纠正的稳定昵称与偏好信息；不等于完整聊天记录，也不拥有业务事实的解释权。
_Avoid_: 全量聊天记录、业务事实副本、每句话都永久记住

**会话上下文**：
NOVA 回答这一轮时可参考的当前有效对话原话、前文摘要和相关事实，不等于跨会话长期记忆。
_Avoid_: 手工偏好列表、全部历史分支

**自动跨会话摘要**：
用户开启一次后，NOVA 从其新对话中持续整理、有原话来源的低风险昵称和偏好；用户可修正、关闭或遗忘，不需要逐条确认才能形成。
_Avoid_: 用户手工维护的外挂列表、正式业务记录、逐字聊天备份

**记忆候选**：
旧版逐条确认流程中的待确认偏好；未确认项不是已保存记忆，也不是当前自动跨会话摘要的前置步骤。
_Avoid_: 自动跨会话摘要、已保存记忆

**业务事实**：
由植宠、设备、任务和养护记录等权威业务对象拥有的真实状态。
_Avoid_: AI 记忆、模型推断

**已发布知识**：
经过内容审核并正式发布、带有来源和更新时间的植物知识。
_Avoid_: 模型常识、未审核草稿、检索片段中的指令

## 建议与行动

**观察**：
对图片、传感器或用户描述中可见现象的记录，不自动构成诊断或任务。
_Avoid_: 确诊、任务

**养护建议**：
NOVA 根据当前证据提出、尚未产生业务副作用的可选做法。
_Avoid_: 指令、已执行动作

**任务候选**：
由 NOVA 生成并等待用户预览、修改或确认的结构化养护安排。
_Avoid_: 自动任务、已创建任务

**正式任务**：
经过用户确认并由业务系统校验、保存的养护安排。
_Avoid_: 任务建议、任务候选

**用户确认**：
用户针对一个明确候选内容作出的同意写入行为，不由沉默、上下文推断或模型代替。
_Avoid_: 模型确认、默认同意

**轮次幂等键**：
客户端为一次发送生成并在网络重试中复用的稳定标识；服务端据此返回同一已提交轮次，不重复保存消息、候选或正式任务。
_Avoid_: 会话标识、每次重试重新生成的随机值

**能力策略**：
在每轮运行前确定可暴露工具、必需只读事实和副作用边界的确定性策略；它不负责判断普通开放式问题是否值得回答。
_Avoid_: 大范围语义拦截、用提示词代替权限

**结果门禁**：
新运行时完成后对工具来源、权限、结构、隐私和内容完整性进行的验收；未通过时回落既有链路，不展示半成品。
_Avoid_: 内容审美评分、模型自我批准

## 迁移与验证

**影子轮次**：
新 Agent 运行时对同一用户输入进行只读处理，只记录脱敏后的决策差异，不接管用户可见回复，也不产生业务副作用。
_Avoid_: 灰度回复、双写、后台 Agent

**受控灰度轮次**：
被稳定抽样到新 Agent 运行时、且只有在所需能力与结果完整性均通过时才由新运行时回复的会话轮次；不通过时仍由既有能力链处理。
_Avoid_: 全量切换、随机单轮、失败即报错
